# 灰雾之上

一个在本机运行的塔罗网站，以《诡秘之主》的灰雾、暗金和神秘学氛围为视觉灵感。无需登录，AI 接口由使用者自行填写。

![灰雾之上的入场画面](docs/preview.jpg)

## 启动

从 [最新发布版本](https://github.com/skyXIANGTIAN13152/grey-fog-tarot/releases/latest) 下载 `grey-fog-tarot-local.zip` 并完整解压。Windows 双击 **`启动灰雾之上.cmd`**，等待浏览器打开 <http://127.0.0.1:4173>。本机需要 Node.js 22.12 或更高版本，启动器也会尝试已有的 Codex Node 运行时。

通过 Git 克隆或 GitHub 的 Download ZIP 获取源码后，请先按下方「开发与构建」安装依赖并执行构建，再运行启动器。

已包含 `dist/` 构建结果时，启动不需要安装项目依赖。请保留整个项目文件夹，不能只复制启动文件。关闭浏览器后，网站服务仍在后台运行；再次启动会复用已经运行的服务。

停止服务：在项目目录打开 PowerShell，运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\stop-local.ps1
```

后台启动日志保存在 `.local/`，服务不会记录接口密钥或对话正文。若 4173 端口被其他程序占用，可先关闭该程序，或运行 `scripts/start-local.ps1 -Port 4174`。浏览器记录按地址和端口分别保存，因此建议始终使用默认地址。

## 可以做什么

- 进入青铜长桌，选好牌阵并写下问题，点「洗牌并亲自选牌」。宽屏默认把整副 78 张牌背朝上扇形铺开，也可以切换为分组选牌。手机按组放大，可以切换到任意一组。第一张点中的牌进入第一个牌位，之后依序放置，选满才可翻牌。
- 确认牌阵前，每个已选牌位都可以点「换这张」。从重新洗好的余牌中选一张替换，或取消并保留原牌。新选的牌背朝上，其余牌位和已翻开的牌保持原状。
- 当前标签页会暂存未完成的牌阵。翻牌后点「完成并查看解读」，最终选择才会写入本机手札，并用于解读和追问。
- 抽牌按钮旁的「仪式动画」默认跟随系统的动态效果设置，手动开关后会记住选择。
- 浏览、筛选和搜索完整 78 张塔罗牌，阅读英文原始资料及新增中文翻译。
- 配置自己的 AI 接口，逐步接收解读，并保留上下文继续追问。
- 在当前浏览器保存占卜记录，重新打开查看，并按需删除。
- 牌库、抽牌和历史记录可在本地离线使用。AI 解读需要你填写的服务可连接；本机模型无需外网。

牌义数据、牌图来源和许可证见 [THIRD_PARTY_NOTICES.md](./THIRD_PARTY_NOTICES.md)。项目为独立同人风格作品，与小说版权方无关联。

## 连接 AI

打开网站的 AI 设置，选择服务或协议，填写接口地址、API Key 和模型名称，然后点击测试连接。模型名称以服务商控制台提供的值为准。

支持三种接口格式：

| 格式 | 地址示例 | 说明 |
| --- | --- | --- |
| OpenAI 兼容 | `https://api.openai.com/v1` | 也适用于提供兼容接口的 DeepSeek、SiliconFlow、自定义服务等；可填写以 `/chat/completions` 结尾的完整地址。 |
| Anthropic | `https://api.anthropic.com/v1` | 使用原生 Messages API。 |
| Gemini | `https://generativelanguage.googleapis.com/v1beta` | 使用原生 Gemini API。 |
| 本机 OpenAI 兼容模型 | `http://127.0.0.1:11434/v1` | 例如已启动的 Ollama，API Key 可留空，模型需预先下载。 |

默认仅在当前浏览器会话保存密钥；勾选“记住密钥”后，密钥会以明文保存在该浏览器的本地存储中。服务端不保存密钥。开始解读或追问时，问题、抽到的牌及必要的对话内容会发送给你选择的 AI 服务；测试连接也会发出一次小请求，可能计入服务商用量。

远程接口需要 HTTPS，本机回环地址可使用 HTTP。网站通过本地服务转发请求，通常无需另行处理浏览器跨域设置。接口服务必须兼容所选协议；不能保证任意第三方接口都可直接使用。

## 开发与构建

需要 Node.js 22.12 或更高版本。项目提供 `pnpm-lock.yaml`，推荐使用 pnpm：

```powershell
pnpm install --frozen-lockfile
pnpm dev
```

开发界面默认使用 5173 端口，AI 本地服务使用 8787 端口。生成可直接启动的版本：

```powershell
pnpm build
pnpm test
pnpm start
```

也可使用 `npm install`、`npm run dev`、`npm run build`、`npm test` 和 `npm start`。生产启动仅依赖 Node.js、`server/` 和生成的 `dist/`，无需 `node_modules/`。

## 验证范围

2026-11-08 发布前重新通过 TypeScript 检查、生产构建及 35 项自动测试。此前浏览器验收覆盖扇形手选、单张换牌、揭牌、中英牌义搜索和筛选、设置保存与刷新恢复、流式解读、连续追问、停止生成、生成期间保存手记、历史恢复、导出和选择删除。已检查桌面及 390 / 320 像素宽度的手机布局。

AI 后端已通过本地模拟接口测试，覆盖三种协议、分块文字、普通 JSON 回复、错误处理、超时和取消。没有使用真实密钥调用收费云端模型；实际账号权限、余额、模型及网络情况需由设置页的连接测试确认。

浏览器本地记录不是云端备份；清除网站数据、切换浏览器或使用不同地址后，原记录可能无法看到。
